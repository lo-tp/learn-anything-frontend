# The chrome is labelled by one identity probe

The top bar offers **either** Explore **or** Study, never both: a Visitor is offered the public feed, a signed-in User their History (#143). Offering one of the two means the chrome has to know who is looking, so the app probes `GET /auth/me` once per page load and shares that answer through `hooks/use-sign-in-state.ts` — the only identity read in the app, and the single place its result is held. This deliberately takes the option ADR-0004 considered and rejected (probing identity to label the chrome): the owner's rule is that the two surfaces are not presented side by side, and a static chrome cannot honour that.

Considered and rejected: showing both tabs and letting a `401` explain itself (what ADR-0004 chose — it offers a User a tab of strangers and a Visitor a dead end, which is exactly what was rejected); gating `/mine` at the edge and redirecting (it re-builds the sign-in gate that #149 removed, and puts the boundary in the route rather than in the API); reading a client-side flag or the cookie (there is nothing to read — the session cookie is `HttpOnly`, so the endpoint's answer is the only signal); letting each component probe for itself (the tabs, the account menu and the deck would each ask: three requests per page load and three chances for the chrome to contradict itself).

Consequences: one extra request per page load, even on the public surfaces that need no identity; the chrome is a Visitor's until the probe answers, on the server too, so the first client render matches the HTML and the flip happens after hydration; a probe the backend cannot answer is read as a Visitor, whose cost is a mislabelled tab and never a wrong write, because every surface that owns data asks again through the sign-in modal when it tries to write; the answer lives in module scope for the page load and is refreshed when the auth signals announce a sign-in — a sign-out needs no request, the fact is already known. ADR-0004's consequence that "a `401` is the only identity signal" still holds; what changed is that its answer is now read deliberately and stored for the page.
